# UAGS — Universal Autonomous Growth System

[Открыть сайт UAGS](https://mitsuoke.github.io/uags-connect/)

Это публичный сайт UAGS с фирменным знаком, объяснением рабочего цикла и первым шагом подключения. Он готовит отдельный профиль и план исследования для публичного HTTPS-сайта **любого направления бизнеса**. Вопросы сразу появляются на странице. Профиль сохраняется в браузере, а публичные сведения о сайте и задаче передаются в отдельную очередь UAGS после нажатия кнопки. Страница не начинает исследование сама и не является защищённым личным кабинетом.

## Порядок подключения

1. Для выбранного сайта укажите его публичный HTTPS-адрес, направление бизнеса и вопрос для исследования.
2. Нажмите «Показать план и передать заявку». План сохраняется в браузере; при реальном HTTP 202 появляется номер полученной заявки. При ошибке план остаётся на странице и отправку можно повторить с его карточки.
3. Внутренний оператор отдельно проверяет заявку и может передать публичный профиль в существующий Engine по [инструкции Engine](https://github.com/mitsuoke/fgn-nn-growth-engine/blob/main/examples/projects/README.md). Получение заявки само по себе не запускает исследование.
4. Предложения по изменению сайта проверяются по его исходнику и целям бизнеса. Право открыть PR, выпустить правку или читать закрытую аналитику оформляется отдельно для каждого проекта.

Не вводите здесь ключи, пароли, данные клиентов или закрытые планы. Отдельная очередь хранит только публичные сведения заявки в D1 EU; запросы удаляются при следующей операции после 30 дней, а не по гарантированному таймеру. У страницы нет аккаунтов, доступа к CRM/аналитике и автоматической публикации. Указанный адрес сам по себе не подтверждает владение сайтом.

Первый интерфейс был выпущен из проверенного набора Engine через [PR #1](https://github.com/mitsuoke/uags-connect/pull/1). Обновлённый сайт и два SVG знака подготовлены в [Engine PR #405](https://github.com/mitsuoke/fgn-nn-growth-engine/pull/405); публичные файлы синхронизированы с данным репозиторием после проверки. Знак UAGS — самостоятельная работа по принципам простоты и устойчивости, изученным в проекте производства; Sagi Haviv не участвовал в её создании и не одобрял её. Другой бизнес владельца — один из возможных будущих проектов, а не условие работы платформы. Реальные внешние бизнес-сайты пока не подключены; FGN и его период наблюдения не затронуты.
