# UAGS — Universal Autonomous Growth System

[Открыть сайт UAGS](https://mitsuoke.github.io/uags-connect/)

Это публичный сайт UAGS с фирменным знаком, объяснением рабочего цикла и первым шагом подключения. Он готовит отдельный профиль и план исследования для публичного HTTPS-сайта **любого направления бизнеса**. Вопросы для исследования сразу появляются на странице. Настройки сохраняются только в вашем браузере; резервные копии доступны в разделе «Дополнительно». Страница пока не запускает Engine и не является защищённым личным кабинетом.

## Порядок подключения

1. Для выбранного сайта укажите его публичный HTTPS-адрес, направление бизнеса и вопрос для исследования.
2. Посмотрите готовый план прямо на странице. Он сохраняется в текущем браузере, но пока не передаётся в Engine автоматически и не синхронизируется между устройствами.
3. Технический оператор может сохранить копию через «Дополнительно» и передать её существующему Engine по [инструкции Engine](https://github.com/mitsuoke/fgn-nn-growth-engine/blob/main/examples/projects/README.md). Это временный внутренний путь, а не действие посетителя.
4. Предложения по изменению сайта проверяются по его исходнику и целям бизнеса. Право открыть PR, выпустить правку или читать закрытую аналитику оформляется отдельно для каждого проекта.

Не вводите здесь ключи, пароли, данные клиентов или закрытые планы. У страницы нет аккаунтов, серверного хранения профилей, доступа к CRM/аналитике и автоматической публикации. Указанный репозиторий сам по себе не подтверждает владение сайтом.

Первый интерфейс был выпущен из проверенного набора Engine через [PR #1](https://github.com/mitsuoke/uags-connect/pull/1). Обновлённый сайт и два SVG знака подготовлены в [Engine PR #405](https://github.com/mitsuoke/fgn-nn-growth-engine/pull/405); публичные файлы синхронизированы с данным репозиторием после проверки. Знак UAGS — самостоятельная работа по принципам простоты и устойчивости, изученным в проекте производства; Sagi Haviv не участвовал в её создании и не одобрял её. Другой бизнес владельца — один из возможных будущих проектов, а не условие работы платформы. Реальные внешние бизнес-сайты пока не подключены; FGN и его период наблюдения не затронуты.
