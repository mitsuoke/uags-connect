# UAGS — подключение сайтов

[Открыть страницу подключения](https://mitsuoke.github.io/uags-connect/)

Это первый публичный интерфейс UAGS. Он готовит отдельный профиль и план исследования для публичного HTTPS-сайта **любого направления бизнеса**. Настройки сохраняются только в вашем браузере; профиль и план можно скачать в JSON. Страница пока не запускает Engine и не является защищённым личным кабинетом.

## Порядок подключения

1. Для выбранного сайта укажите его публичный HTTPS-адрес, направление бизнеса и вопрос для исследования. Публичный репозиторий GitHub можно указать дополнительно.
2. Скачайте профиль и план. Храните файлы у себя; настройка в этом браузере не синхронизируется между устройствами.
3. Владелец существующего Engine импортирует профиль по [инструкции Engine](https://github.com/mitsuoke/fgn-nn-growth-engine/blob/main/examples/projects/README.md) и запускает публичное исследование. Доступ к приватному Engine нужен отдельно.
4. Предложения по изменению сайта проверяются по его исходнику и целям бизнеса. Право открыть PR, выпустить правку или читать закрытую аналитику оформляется отдельно для каждого проекта.

Не вводите здесь ключи, пароли, данные клиентов или закрытые планы. У страницы нет аккаунтов, серверного хранения профилей, доступа к CRM/аналитике и автоматической публикации. Указанный репозиторий сам по себе не подтверждает владение сайтом.

Код страницы выпущен из проверенного набора восьми файлов Engine через [PR #1](https://github.com/mitsuoke/uags-connect/pull/1). Другой бизнес владельца — один из возможных будущих проектов, а не условие работы платформы. Реальные внешние бизнес-сайты пока не подключены; FGN и его период наблюдения не затронуты.
