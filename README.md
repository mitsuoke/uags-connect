# UAGS — подключение сайта

[Открыть страницу подключения](https://mitsuoke.github.io/uags-connect/)

Это публичная страница для подготовки профиля **ещё одного сайта** в существующей системе UAGS. Она создаёт план исследования и сохраняет настройки только в вашем браузере. При необходимости профиль и план можно скачать в JSON.

## Порядок подключения

1. После создания сайта укажите его публичный HTTPS-адрес, направление бизнеса и вопрос для исследования. Публичный репозиторий GitHub можно указать дополнительно.
2. Скачайте профиль и план. Храните файлы у себя; настройка в этом браузере не синхронизируется между устройствами.
3. Владелец существующего Engine импортирует профиль по [инструкции Engine](https://github.com/mitsuoke/fgn-nn-growth-engine/blob/main/examples/projects/README.md) и запускает публичное исследование. Доступ к приватному Engine нужен отдельно.
4. Предложения по изменению сайта проверяются по его исходнику и целям бизнеса. Право открыть PR, выпустить правку или читать закрытую аналитику оформляется отдельно для каждого проекта.

Не вводите здесь ключи, пароли, данные клиентов или закрытые планы. У страницы нет аккаунтов, защищённого кабинета, серверного хранения профилей, доступа к CRM/аналитике и автоматической публикации. Указанный репозиторий сам по себе не подтверждает владение сайтом.

Код страницы выпущен из проверенного набора восьми файлов Engine через [PR #1](https://github.com/mitsuoke/uags-connect/pull/1). Второй бизнес и его сайт ещё не подключены. FGN и его период наблюдения не затронуты.
